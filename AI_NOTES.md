# AI Usage Notes

## AI Tools Used

- ChatGPT (OpenAI)

AI was used as a development assistant throughout this project for guidance, code review, debugging, and improving code quality. All generated code was reviewed, tested, and modified before being included in the final submission.

---

## AI-Generated vs. Self-Written Work

### AI Assisted

- Initial FastAPI project structure
- Suggestions for API endpoint organization
- JSON storage implementation ideas
- Test case examples using Pytest
- Documentation structure (README and AI_NOTES)
- Suggestions for improving API response consistency

### Implemented and Validated by Me

- Complete project setup and environment configuration
- API endpoint implementation and integration
- Project structure and file organization
- Manual testing using Swagger UI
- Automated testing using Pytest (10 passing tests)
- Debugging import issues, virtual environment issues, and routing errors
- Monthly Summary bonus feature integration
- Git repository setup and project organization

---

## Validation and Changes Made

The AI-generated suggestions were not used without verification.

I validated the implementation by:

- Running the FastAPI application locally
- Testing every endpoint using Swagger UI
- Executing automated tests with Pytest
- Debugging import, routing, and virtual environment issues
- Refactoring API responses into a consistent structure using `success`, `message`, and `data` fields

Several AI suggestions were modified to better match the assignment requirements and improve code readability.

---

## AI Suggestions Not Used

Some AI suggestions were intentionally not implemented, including:

- Database integration (SQLite/PostgreSQL)
- Authentication and authorization
- Frontend charts and dashboards
- Docker support
- Additional production-level features beyond the assignment scope

These features were excluded to keep the implementation aligned with the assignment requirements, which specified local storage without requiring a database.

AI was used as a development assistant to improve productivity and code quality. All code included in the final project was reviewed, tested, and understood before submission.
